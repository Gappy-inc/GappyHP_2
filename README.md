# Gappy Corporate Website

The production corporate website for [gappy.jp](https://gappy.jp).

## Positioning

Gappy builds AI Workforce for Travel Operations. The site is the canonical corporate source for Gappy and 株式会社Gappy.

## Local development

```bash
npm ci
npm run dev
```

## Validation

```bash
npm run lint
npm run build
```

The canonical production host is `https://gappy.jp`.
